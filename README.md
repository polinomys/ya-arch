Задание 1. Разделение проекта на микрофронтенды.

Для разбиения проекта предлагается использовать инструмент webpack mf.

Можно выделить следующие компоненты:

1) Точка входа в приложение (host)
2) Аутентификация пользователя (auth)
3) Изменение профиля пользователя (profile)
4) Взаимодействие с карточками (main)

Задание 2. Декомпозиция web-приложения на Django.

Файл со схемой лежит в корне: https://github.com/polinomys/ya-arch/blob/sprint_1/arch_template_task2_new.drawio

Целесообразно выделить следующие сервисы (системы):

0) Портал электронной площадки.
Без изменений.

1) Аутентификация и авторизация.
Осуществляется регистрация новых пользователей, авторизация и аутентификация пользователей, формируется jwt-токен.

2) Управление профилями пользователей.
Хранение данных о пользователях - участниках (покупателях и продавцах) площадки.

3) Управление товарами и услугами
Актуализация данных о товарах и услугах пользователей.

4) Управление заказами
Формирование заказов пользователей. Заказ может формироваться из товара или услуги.

5) Управление аукционами
Формирование аукционов, управление аукционами.

6) Техническая поддержка, аппеляция
Обращение в техническую поддержку.

7) Отчетность и нотификация
Сервис предоставляет функционал для построения отчетности и нотификации пользователей.
Для нотификации сформированы специальные шаблоны сообщений.

8) Платежный шлюз
Осуществляет взаимодействие с внешними платежными системами.
